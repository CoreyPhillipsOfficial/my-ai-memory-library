# Contributing

Keep changes small and focused on the archive, search, and recovery workflow. Open an issue for larger design changes before adding infrastructure or dependencies. Use fictional notes in examples and tests. Never include your private notes, generated personal indexes, tokens, or conversation transcripts in a report or pull request.

Use Node 22 or newer. Run `npm ci`, `npm run check`, and `npm run index` before submitting. If the builder changes, include a test that covers the behavior. Describe what you ran and any limits you could not verify.

Contributions are offered under the MIT license in [LICENSE](LICENSE).
