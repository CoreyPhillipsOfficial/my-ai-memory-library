# Roadmap

- Prove onboarding with people new to GitHub and record real setup times.
- Add verified instructions for other assistants only after testing their current read and write tools.
- Improve search ranking only if ordinary users struggle to find notes with exact words.
- Consider an optional dashboard if there is a clear need for browsing and editing outside AI conversations.

These are ideas, not promises. The Markdown files must stay usable without future features.
