# Assistant instructions

Read `README.md` and `docs/ASSISTANTS.md` before editing notes. The Markdown files in `notes/` are the source of truth. `index.json` and `index/` are generated and may lag a write.

Search before creating. Read likely matches in full, then update a matching note or create a new one. Preserve useful prior findings and mark uncertain claims. Never save credentials or an entire conversation unless the user explicitly requests it. Use the latest file version or SHA for edits, handle conflicts by merging, and read a saved note back. Do not edit generated index files manually. Report when a write or index check could not be verified.

These instructions only apply when an assistant has been told to read this file. A repository connection does not load them automatically.
