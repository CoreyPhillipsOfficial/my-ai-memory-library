# One-minute demonstration

This is a recording script, not a claim that a video or two assistant conversations were recorded. Use a **private repository made from this template**. Use only the fictional example below.

## Preparation

Connect an assistant that has GitHub read and write tools to the private demo repository. Paste the prompt from [Assistant setup](ASSISTANTS.md) with the demo repository name. Delete any test notes from earlier takes. Start a screen recording with notifications hidden. Do not show credentials or private account details. If your assistant cannot write, show the GitHub web editor save step and say so in the recording.

## 45-second shot list

1. **0–8 seconds:** In conversation A, say: “I volunteer at the fictional Moonlight Library. We lend telescopes on Fridays. They must be returned by Sunday noon.”
2. **8–20 seconds:** Say: “Archive this to my knowledge hub.” Show the assistant searching for a match, saving a short note, and reading it back. Display the saved Markdown file briefly.
3. **20–25 seconds:** Open a separate conversation. Show that this is a new chat.
4. **25–40 seconds:** Ask: “When does the Moonlight Library need its telescopes back?” Show the assistant fetching the saved note and answering “Sunday noon,” with its note path.
5. **40–45 seconds:** End on: “Your notes are Markdown files in your private GitHub repository.”

Trim waiting time, but do not edit around a failed write or retrieval to imply success. If the index workflow is still running, show a direct note read and say the index is pending. Keep the final recording between 30 and 60 seconds.
